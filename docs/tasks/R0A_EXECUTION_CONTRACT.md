## Persistence (Codex 5.6)

Tables execution (identity/spec/state JSON plus queryable columns), execution_event, resource reservation enforced by unique partial indexes for one active execution per ticket, assignment AND cwd. UNKNOWN counts as active. Terminal states alone release active uniqueness. Existing LocalStore owns connection/transactions.

API: reserve(spec: ExecutionSpec): ExecutionRecord; get(executionId): ExecutionRecord|undefined; list(): ExecutionRecord[]; events(executionId, afterSequence=0): ExecutionEvent[]; apply(event: ExecutionEvent): ExecutionRecord. reserve is idempotent only for exactly equal same execution spec; any difference rejects. Require safe IDs, nonempty identity, generation positive integer, absolute cwd, revision/policy. apply validates full event shape, matching executionId/generation, monotonic contiguous sequence starting 1, duplicate same sequence only if exact same contents; reject changed duplicate, stale generation, invalid transitions, terminal replacement. Allow first sequence1 STARTING event to bind runner identity without changing initial STARTING state. Allow STARTING->RUNNING/FAILED/UNKNOWN/STOPPING, RUNNING->STOPPING/SUCCEEDED/FAILED/TIMED_OUT/CANCELLED/UNKNOWN, STOPPING->CANCELLED/TIMED_OUT/FAILED/UNKNOWN, UNKNOWN->RUNNING/STOPPING/any terminal only on same runner identity. Bind runnerId on first event; reject foreign runner. Final states require exit proof: an integer exitCode or nonempty signal; successful must have exitCode0 and no signal; startup failure allows no child process but requires explicit reason. State/events/uniqueness update atomic and rollback all changes on failure. Test crash/reopen, multiple connections duplicate reservations, UNKNOWN retaining slot, stale/conflicting events, transaction rollback and valid completion. No modifications to LocalStore or manifest; parent will integrate.

## Runner worker (pi)

Only src/runner/worker.ts. Export runWorker(requestPath:string): Promise<void>, with main guard executable via node dist/runner/worker.js --request PATH. Private protocol files inside execution directory: request.json (RunnerRequest), state.json (RunnerSnapshot), events.jsonl (RunnerEvent lines), stdout.log, stderr.log, stop.json (StopRequest). Validate spec/token/version and absolute command/cwd; never execute shell. Claim worker ownership exclusively using worker.lock (wx); duplicate worker cannot spawn a second child. Writes mode0600, directory0700, atomic snapshot replacement; append/fsync ordered lifecycle events, no credentials in events. Snapshot sequence starts1 STARTING, RUNNING after spawn; heartbeats every250ms update same snapshot without adding event. No parent IPC dependency; process stays alive independently. Runtime child own process group on POSIX. Child environment minimal PATH/HOME/USER/LANG/TMPDIR, no inherited API keys. stdout+stderr combined byte bound; on exceed terminate process group, classify FAILED with reason. Stop file polled every50ms and token must match; termination SIGTERM then SIGKILL after graceMs. Timeout TIMED_OUT, manual stop CANCELLED; never success after termination was requested. Wait close + logs flush/fsync before terminal event. Enforce no surviving process-group members before claiming terminal, including descendants that outlive the direct child; otherwise UNKNOWN retains ownership. Kill/monitor timers bounded and cleaned. Runtime output does not decide SUCCEEDED beyond exitCode0 (Runner is process outcome only; Claude Adapter will validate protocol). Child startup errors FAILED with reason and no pid. Robust on stdin EPIPE; stdin ignored because protocol fixtures supply argv. Do not delete execution files/lock on finish. A crashed worker cannot be relaunched against existing lock; needs reconciliation. No tests assigned; parent/Claude writes integration tests.

Request creation and launch can have a crash window; duplicate start never launches another worker. Existing directory: verify canonical stable spec equality, return existing status; missing request/state returns explicit UNKNOWN error, never retry spawning. Read snapshots validate identity against request and ID/generation, do not trust malformed/unrecognized state. Enforce safe ID/path, real root and execution directory not symlink, private root0700 (reject preexisting shared root rather than chmod), owned files no symlinks. status maps nonterminal to UNKNOWN if stale heartbeat or missing runner pid; pid0 check alone never permits killing or restarting unknown process. terminal snapshot may return even old. stop writes authenticated stop.json atomically only for live fresh nonterminal; terminal accepted false (already finished); unknown accepted false (must reconcile). events validates complete JSON lines in sequence and identity; ignore only one trailing incomplete line from in-progress append, reject malformed completed lines.
