# Parallel foundation packages

All packages: isolated worktree, assigned files ONLY, read AGENTS.md. Node builtins only; no package installation, secrets, commits/pushes, model API calls or nested delegation. Do not modify shared schema/hooks or existing files; parent handles integration. Database modules expose explicit initializer(db), use kv namespaced schema version1, reject future versions before writes, use savepoints for nested transaction safety. Validate inputs at runtime, return defensive copies, test real temporary SQLite/filesystems. Missing integration is to be reported, never fake readiness. All paths absolute when accessing disk, do not follow untrusted symlinks or delete foreign data.
